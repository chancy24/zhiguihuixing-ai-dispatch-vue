# 路演演示脚本

明天路演推荐演示路径：

1. 登录进入系统。
2. 首页驾驶舱，说明今日任务、冲突、疲劳预警和数据来源。
3. 时刻表管理，演示导入、站名转换、重要站摘抄、内外环分类。
4. 乘务片段划分，演示一键划分和规则校验。
5. 智能排班，演示候选方案对比和 AI 辅助建议。
6. 应急重排，选择“2名乘务员请假”，展示影响分析和替换建议。
7. Agent助手，输入自然语言问题并生成建议。
8. 方案解释与报告，导出报告。
9. OPC赋能展示，说明阶段化 MVP 验证路径。

讲解重点：

- 项目来自真实排班规则，不是凭空概念。
- AI 化围绕排班、重排、校验、预警、解释和报告展开。
- 当前是 MVP 演示版，AI 只辅助建议，调度员最终确认。
