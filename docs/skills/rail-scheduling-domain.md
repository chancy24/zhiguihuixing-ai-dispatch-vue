# 轨道交通排班业务规则

系统功能应围绕城市轨道交通乘务排班真实规则展开：

- 站名转换：如 BG -> 巴沟、SJZ -> 宋家庄、WLPL -> 五路。
- 内外环分类：根据方向字段、服务号或线路运行方向识别内环/外环。
- 早白夜班识别：04:16-07:15 为早班，15:46-19:37 为夜班，其他为白班。
- 乘务片段划分：根据服务号、车次、起终点、发到时间生成片段。
- 工时限制：连续工作时间超过上限应标记冲突。
- 间休校验：低于最小间休或超过最大间休应提示原因。
- 出退勤地点校验：出勤和退勤地点应在允许站点组合范围内。
- 用餐时间校验：白班应满足午餐休息窗口或提示需复核。
- 里程限制：片段里程超限应标记风险。
- 疲劳风险评分：结合连续工作、夜班频次、休息间隔、近 7 日工时计算。

所有页面按钮、提示、表格状态和 AI 建议都应尽量回到这些规则，而不是停留在泛泛的 AI 描述。
