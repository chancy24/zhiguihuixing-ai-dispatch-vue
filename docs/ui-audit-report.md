# 智轨慧行 UI 真实性自查报告

> 检查日期：2026-07-06
> 检查范围：登录页 / 首页驾驶舱 / 排班工作流 / 线路基础管理 / 时刻表管理 / 乘务片段划分 / 智能排班优化 / 应急重排 / 疲劳风险预警 / 排班Agent助手 / 报告页 / OPC赋能页 / 路演模式页
> 检查方式：逐页代码审计 + 构建验证（`npm run build` 通过）

## 一、总体结论

本轮升级前，项目存在 4 类共性问题：①真实图片/线路图素材为零，"图形"均为 div 圆点或灰底文字占位；②`beijingLine10.ts`（45站完整数据）为死代码，各页仍在用更简陋的旧 `mock/*`；③`.status-info` 徽标配色缺失，大量 info 标签呈裸文字；④免责声明机械重复 7+ 次。本轮已逐项修复，并新增 DeepSeek 大模型调度Agent工作台。

构建状态：`npm run build`（vue-tsc --noEmit && vite build）✅ 通过，89 模块，1.85s。

## 四、DeepSeek 调度Agent接入说明

- 密钥存放：`.env.local`（`VITE_DEEPSEEK_API_KEY`，已加入 `.gitignore`）
- 服务：`src/utils/deepseek.ts`，OpenAI 兼容协议，模型 `deepseek-chat`
- 工作台：`src/views/AgentAssistantView.vue`，注入10号线站点/时刻表/乘务员/规则上下文
- 降级：无密钥或接口失败时，自动切换本地规则引擎（`buildLocalReply`），保证演示不中断
- ⚠ 安全：浏览器直连会暴露密钥，仅用于路演；正式部署需改为后端代理。用后请在 DeepSeek 平台轮换密钥
